# Código de ejemplo para las pantallas

Cinco pantallas educativas HTML y un JavaScript compartido que usa `fetch` contra la API de Erlang.

**No corresponde al frontend original completo**: la interfaz real usa otros archivos, eventos, gráficos y estilos. El ejemplo no contiene datos falsos: intenta consultar la API y muestra un error cuando no está disponible. Para usarlo hay que servir los HTML desde el **mismo origen** del backend Cowboy (o configurar CORS y la URL de API con autorización del backend).

Consulta [Incorporar código real](../../docs/INCORPORAR_CODIGO_REAL.md) para obtener HTML/JS auténticos desde AWS.
